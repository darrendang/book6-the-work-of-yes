# Book 6 — Pattern Log

Emerging patterns are hypotheses, not canon, until explicitly approved.

## Initial patterns to test

- Premature no
- Institutional self-protection
- Local optimization versus responsibility for the whole
- Constraint versus requirement
- Guardrail versus roadblock
- Requirement versus assumption
- Reframing the objective
- Alternative architecture
- Constructive constraint
- Earned yes
- Earned no
- Stewardship under constraint

## Candidate sequence

Objective → apparent constraint → easy no → deeper inquiry → distinguish requirement from assumption → reframe → generate alternatives → test against guardrails → workable path or justified stop → earned yes / earned no.

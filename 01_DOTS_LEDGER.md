## Seed dot 001 — Matt / CISO / Microsoft Fabric

**Status:** mined seed example

A legitimate security constraint appeared around Fabric development, test, UAT, and production environments. The important move was to treat security requirements as design constraints rather than as an automatic conclusion. The question shifted from “Can we do this?” to “What does security actually require, and what architecture can satisfy those requirements while accomplishing the objective?”
